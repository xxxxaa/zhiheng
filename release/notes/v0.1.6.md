# 知衡 0.1.6

**浏览器卡在“已下载全部大小”时：** 请取消当前 APK 下载，改用 [ZIP 安装包](https://github.com/xxxxaa/zhiheng/releases/download/v0.1.6/zhiheng-0.1.6-android.zip)。在文件管理器中解压，打开其中的 APK 直接覆盖安装，不要先卸载。

- 更新页显示当前安装版本，并直接提供 ZIP 备用下载按钮。
- 检查更新时重新获取版本清单，避免继续使用缓存的旧版本。
- 支持 App 内下载、进度、取消重试和安装包校验，校验通过后由系统确认安装；旧版用户需先用 ZIP 完成本次覆盖升级。
- 接入东方财富沪深北 A 股延迟行情，支持手动刷新或前台解锁时每 60 秒自动刷新。
- 自动重算持仓市值、净资产和浮动盈亏，保留报价时间；失败、过旧报价及查询期间的编辑不会覆盖原估值。持股数量、成本和现金仍由用户维护。

安装后可在“偏好与连接 → 应用更新”使用“在 App 内下载更新”，在“东方财富行情估值”开启行情自动更新。
