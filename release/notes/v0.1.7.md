# 知衡 0.1.7

- 新增「市场资料」：接入东方财富妙想 MCP，可查询 A 股、港美股、基金、债券、指数、宏观、公告、新闻及筛选数据。
- 查询结果保留数据日期与单位，以表格展示；可选择「用于 AI 分析」，将本次资料交给已配置的 DeepSeek 或其他模型。
- 在「偏好与连接」填写自己的妙想 API Key，可验证连接，并随模型和搜索密钥一起加密保存在本机。兼容已有密钥库。
- 仅向妙想发送你输入的查询词，不自动上传账本。自然语言查询不直接覆盖持仓估值，现有 A 股延迟行情估值功能保持独立。
- 查询支持取消、90 秒超时和错误提示；资料缺少网页来源或被截取时明确说明。

直接覆盖安装，无需卸载旧版。安装包不包含任何用户的妙想 Key，需在 App 内自行填写。
