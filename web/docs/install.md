# 安装与离线使用

主交付现为 Android / iOS 安装版，见[手机 App 说明](mobile.md)。本文保留浏览器版本的安装与离线行为，不能用于安装 APK 或 iOS App。

知衡是可以添加到手机主屏幕的 Web App。静态托管负责分发 App 文件，资产保存在设备本机；不依赖 Sites 或其他指定托管商。

## 放到手机上

1. 把生产构建 `dist/` 中的文件放在一个固定 HTTPS 域名的根目录。保留目录结构，并让 `/sw.js` 返回 JavaScript，不要重写成 HTML。
2. 用手机系统浏览器打开这个地址。在“偏好与连接 → 安装与离线使用”确认显示“离线使用已准备好”。这个提示会检查当前生效缓存中的全部必要文件，不只检查注册是否成功。
3. iPhone / iPad：在 Safari 分享菜单中选择“添加到主屏幕”；出现“作为网页 App 打开”时开启。Android：使用浏览器菜单中的“安装应用”或“添加到主屏幕”；支持安装提示的浏览器也会在 App 中显示“安装知衡”按钮。
4. 从主屏幕图标打开，用合成数据试一次关闭、离线重开、修改并保存。设备锁也应在这个最终地址中设置。

安装菜单因浏览器和系统版本而异。内嵌浏览器可能不提供安装或设备验证功能；应在系统浏览器中完成。具体 iPhone 操作参考 [Apple 官方说明](https://support.apple.com/guide/iphone/bookmark-a-website-iph42ab2f3a7/ios)，安装按钮的浏览器限制见 [MDN](https://developer.mozilla.org/en-US/docs/Web/API/BeforeInstallPromptEvent)。

## 离线与更新

离线支持本机账本读取、编辑、健康指标计算和加密文件导出。AI、搜索及 S3 备份需要网络；S3 仍按打开且解锁后补做的方式工作。

新版本下载完成后，会提示关闭全部知衡窗口，下次打开时启用。不会强制刷新正在编辑的页面。缓存只包含 App 页面、代码、样式与图标，不缓存 API 回答、网页正文或云备份文件。更新不会清除 IndexedDB 账本。

如果提示缓存未完整下载，保持联网并重新检查。浏览器清除或回收站点存储会同时影响本地数据与离线文件，应保留加密备份。更换域名或浏览器需要通过备份迁移，设备验证需要重新设置。

这证明该浏览器下的离线页面与本机读写流程；不代替真实 iOS / Android 的主屏幕安装和设备验证验收。
